# Power BI Sales Analysis Dashboard 📊

## Project Overview

This project presents an interactive **Sales Analysis Dashboard built using Microsoft Power BI**. It provides a visual overview of sales performance, transaction activity, product quantities, customer ratings, and geographical sales distribution.

The dashboard combines key performance indicators (KPIs), charts, and interactive filters to help users explore sales data and identify patterns across different dimensions.

## Objectives

- Monitor overall sales performance through key metrics.
- Analyze total quantity and transaction counts.
- Track average sales performance.
- Explore city-wise sales distribution.
- Understand transaction distribution across payment methods.
- Analyze customer ratings.
- Examine monthly quantity trends.
- Compare brand-level performance.
- Enable interactive data exploration using slicers.

## Tools and Technologies

- **Microsoft Power BI** — Dashboard development and interactive reporting
- **Power Query** — Data preparation, if used in the project
- **DAX** — Measures and calculations, where applicable
- **Data Visualization** — KPI cards, maps, line charts, pie charts, funnel charts, and tables

## Dashboard Features

### 1. Key Performance Indicators

The dashboard displays four primary metrics:

- Total Sales
- Total Quantity
- Transactions
- Average Sales

These KPIs provide a quick overview of the overall business performance.

### 2. Geographical Sales Analysis

A map visual represents sales across cities, helping users explore the geographical distribution of sales activity.

### 3. Monthly Trend Analysis

A line chart visualizes total quantity by month, making it easier to examine changes in sales volume over time.

### 4. Payment Method Analysis

A pie chart shows the distribution of transactions across different payment methods, allowing comparisons between payment preferences.

### 5. Customer Ratings

A funnel visual displays customer rating values and their associated counts, providing a view of the distribution of ratings in the dataset.

### 6. Brand Performance

A table compares brands using total sales, total quantity, and transaction counts.

### 7. Interactive Filters

The dashboard includes filters for:

- Month
- Payment Method
- Brand
- Mobile Model

These filters allow users to focus on specific periods, brands, products, or payment methods and explore the corresponding metrics.

## Dashboard Insights

The dashboard is designed to help users investigate questions such as:

- How do sales and transaction volumes vary across cities?
- How does total quantity change over different months?
- Which payment methods account for the largest share of transactions?
- How do sales and quantities compare across brands?
- What patterns appear in customer ratings?
- How do the KPIs change when a particular brand, month, or mobile model is selected?

Specific business conclusions should be drawn from the values and patterns observed in the dashboard.

## How to Use the Project

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `PowerBi_project.pbix` in Power BI Desktop.
4. Explore the KPI cards, charts, map, and brand performance table.
5. Use the available slicers to interact with the dashboard.

**Note:** The dashboard's data source may need to be reconnected or refreshed if the original source files are not included in the repository.
